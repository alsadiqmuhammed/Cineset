# تطبيقي الشخصي (Flutter / Android)

تطبيق يمثلني بكل أقسامه: أعمالي، العدّة، برتي ليدي، أدوات التصوير، المختبر، تطبيقاتي، حياتي وعائلتي، ودفتر الأفكار. يشتغل بدون إنترنت.

## الأقسام
- **أدوات التصوير**: أوقات الساعة الذهبية والزرقاء (البصرة، شط العرب، بغداد، أربيل)، حاسبة الأنامورفيك (Sirui Venus 1.6x)، الشتر وفليكر 50Hz، وحاسبة التخزين.
- **المختبر**: تحويل الوحدات بين mg/dL وSI (Glucose، Cholesterol، Creatinine، HbA1c...).
- **برتي ليدي**: الموقع، الدوام، حالة "مفتوح/مسدود" هسه، وأزرار الخريطة والاتصال والواتساب.
- **دفتر الأفكار**: أفكار السيناريو والحملات واللقطات، تنحفظ على التلفون.

## تعديل المحتوى
كل النصوص بملف `lib/data/profile.dart`. حط رقم برتي ليدي بـ `Salon.phone` (مثلاً `9647701234567`) حتى تظهر أزرار الاتصال والواتساب.

## البناء
Flutter 3.47 وAndroid SDK:

```bash
flutter test
flutter build apk --release --split-per-abi --target-platform android-arm64
# build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
```

النسخة الحالية موقّعة بمفتاح debug. للتحديثات على نفس التلفون استخدم نفس المفتاح دائماً.
