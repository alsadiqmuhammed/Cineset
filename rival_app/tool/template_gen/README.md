# مولّد القوالب

يرسم عائلات القوالب (دمج، دمج قطري، ذوبان، ضباب، هالة، بولارويد، كروت، أشكال، شق، ذهبي، أبيض وأسود، تبويب، بانوراما،
عدسة، تابلت، زجاج، ختم، سكربت) للقسمين، فاتح وغامق، بوست وستوري ومربع.

```bash
# من مجلد فيه node_modules/playwright
mkdir -p tpl4/out && cp gen.html gen.mjs tpl4/
node tpl4/gen.mjs tpl4/out
```

يطلع PNG لكل قالب و`meta.json` بالشبابيك والأقنعة؛ القوالب تتحول WebP
وتنكتب بـ `lib/templates_more.dart`. أشكال السن والقطرة بنفس أرقام
`lib/photo_fx.dart` حتى فتحة القالب تطابق قناع الرسم.
