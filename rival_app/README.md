# تطبيق عيادة ريڤال (Rival Clinic App)

تطبيق أندرويد (Flutter) للعيادة، يشتغل بدون إنترنت وكل البيانات تبقى على التلفون.

## المميزات (حسب وثيقة المتطلبات)
1. **محاذاة الصور بالذكاء الاصطناعي**: يكشف الوجه على التلفون (Google ML Kit، بدون إنترنت) ويأخذ زاويتي الفم كنقطتي محاذاة. صورة "بعد" تتحجّم وتدور وتنزاح حتى تتطابق مع "قبل". لصور داخل الفم (بدون وجه) تحدد النقطتين بإيدك مع عدسة تكبير.
2. **قوالب PNG شفافة**: فريق الجرافيك يرفع إطارات وعروض الحملات من تبويب "القوالب"، وتنرسم فوق التصميم.
3. **فيديو التحوّل**: فيديو عمودي MP4 بمقاس 1080×1920، حوالي 5 ثواني: "قبل" ثم انتقال تدريجي لـ"بعد" مع تقريب خفيف. القالب يبقى ثابت فوق. يتصنع على التلفون (MediaCodec).
4. **أرشيف المراجعين**: ملف لكل مراجع (الاسم والهاتف) بحالاته وصوره، مع بحث، واتصال وواتساب. الصور محفوظة داخل التطبيق وما تختلط بألبوم الكاميرا.
5. **الواجهة**: داكنة بلون ذهبي هادئ، وبالعربي بالكامل.

التصاميم تتصدّر بمقاس منشور 4:5، أو ستوري 9:16، أو مربع، جنب بعض أو فوق وتحت، وتنحفظ بألبوم "Rival" أو تنشارك مباشرة.

## تعديل الهوية
الألوان واسم العيادة بملف `lib/theme.dart`.

```bash
flutter test

```
